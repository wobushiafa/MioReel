## 核心功能（每一项都遥遥领先）

### 🎬 沉浸追剧，功能栏懂事隐身
- **智能控制栏显隐**：正常窗口看剧时，鼠标移出视频画面或静置 3 秒无移动自动隐藏底部控制栏，绝不遮挡字幕；鼠标回到画面立刻呼出。
- **丝滑换集预加载**：自动提前缓冲下一集，支持单集播完自动连播、断点续播与观影历史同步。
- **画质倍速随心调**：支持 1080P / 720P / 480P 清晰度切换与 0.75x ～ 3.0x 记忆倍速，切集、重开依然保留你的习惯。

### 🪟 摸鱼专精：自适应比例悬浮小窗
- **真·按画面比例缩放**：横屏剧、竖屏剧自动匹配原始画幅比例，拖动小窗任意边角或滚动鼠标滚轮，窗口严格按视频比例等比放大缩小，绝不留丑陋大黑边。
- **无感防打扰**：切到小窗时若鼠标不在小窗内，功能栏默认隐身只留纯粹画面；支持窗口置顶、右键/双击显隐控制栏，以及一键还原大窗。

### 🕶️ 老板键 & 全局热键（打工人刚需）
- **一键隐身**：支持系统级**全局老板键**，哪怕当前焦点不在播放器，按下快捷键瞬间暂停播放并隐藏窗口，再按秒速恢复追剧。
- **全键盘操控**：支持自定义播放/暂停、快进快退、倍速调节、上下集、切换小窗、还原窗体等快捷键，自动检测冲突。

### 📥 离线批量缓存
- 支持剧集列表前 20 集或全集一键离线缓存，支持任务暂停、继续、失败重试与断点续下，断网也能流畅本地追剧。

### 🎨 双主题影院观感
- 内置**深色影院**与**浅色日间**双主题，支持片库分类浏览（真人剧 / 漫剧 / AI 剧）、全库检索与搜索记录。

## 快速上手

1. 启动客户端后，进入 **设置 → 存储与服务** 填写视频源服务地址与访问令牌（如有），点击 **连接并同步** 即可开看（也支持通过环境变量 `MIOREEL_GATEWAY_URL`、`MIOREEL_GATEWAY_TOKEN` 预设）。
2. 在播放页点击 **缓存** 可将剧集下载到本地目录；离线剧集可在 **离线下载 → 已完成** 中直接播放。
3. 在 **设置 → 快捷键与全局热键** 中可自定义老板键与各类播放快捷键。
4. 在 **设置 → 账号与云同步** 中填写账号服务地址并用账号密码登录（首次使用可注册），观看历史会在多台电脑之间自动同步。

## 账号与观看历史云同步

功能由两部分组成：桌面客户端（本项目）与自建账号服务 `src/MioReel.Api`（ASP.NET Core Web API，可部署到 IIS）。

方案使用**账号 + 密码**登录：客户端把用户名密码提交到自建账号服务 → 服务端校验 PBKDF2 加盐哈希 → 签发自有 JWT → 客户端保存 token 并同步历史。整个链路直连你自己的服务，**没有第三方中转、无需微信/小程序资质、无需备案域名**；密码永不落盘到客户端，服务端也只存不可逆的哈希。

### 一、部署账号服务到 IIS

1. 安装 **.NET Hosting Bundle**（版本需 ≥ 本项目的 `net11.0`）。
2. `dotnet publish src/MioReel.Api/MioReel.Api.csproj -c Release -o ./publish/api`，把 `publish/api` 内容部署到 IIS 站点。
3. 站点应用程序池设为 **无托管代码**（No Managed Code），项目自带 `web.config`（AspNetCoreModuleV2）。
4. 编辑站点下的 `appsettings.json`：
   - `Jwt:Secret`：改成自己的长随机字符串（≥32 位），**所有客户端必须指向同一个服务**。
   - `Jwt:LifetimeDays`：登录有效期，默认 30 天。
   - `Storage:DataDirectory`：数据目录，默认站点下 `App_Data`，需给 IIS 应用池身份写权限。
5. 确认 `GET https://你的域名/api/health` 返回 `"status":"ok"`、`"authMode":"password"`。
6. 安全建议：账号服务走 **HTTPS**（否则密码明文会在传输中被窃听）。IIS 绑定证书后，客户端地址填 `https://...` 即可。

### 二、客户端使用

1. **设置 → 账号与云同步** → 账号服务地址填 IIS 站点根地址（如 `https://account.example.com`）。
2. 点「登录 / 注册」→ 首次使用切换到「注册新用户」创建账号，之后用同一账号密码登录 → 客户端自动把本地历史并入云端、再回填合并结果。
3. 之后播放进度约每 15 秒节流上传；删除/清空历史同步到云端；在另一台电脑用**同一账号登录**即可继续观看。未登录时历史仍只存本机，不影响离线使用。

### 三、安全说明

- 密码在客户端不落盘（只保存服务端签发的 token），服务端用 **PBKDF2-SHA256 + 16 字节随机盐 + 10 万次迭代** 存储哈希，明文书不存在任何日志或文件里。
- 用户名大小写不敏感且唯一；JWT 载荷只含规范化用户名与过期时间，签名用 HS256。
- 历史按账号隔离，单文件 JSON 持久化（`App_Data/account-store.json`），适合个人/小规模使用。
- 部署前请务必修改默认 JWT 密钥 `Jwt:Secret`；多人共用场景建议增加注册审批或限速。
