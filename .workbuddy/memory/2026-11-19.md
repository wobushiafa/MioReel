## 新增：账号登录 + 观看历史跨设备同步

用户方案选择：自建 .NET Web API（部署 IIS）+ 微信扫码登录（不走 WorkBuddy 云服务）。

### 架构
- 新增 `src/MioReel.Api`（ASP.NET Core Web API，net11.0，无第三方包依赖）：
  - 微信扫码登录：`POST /api/auth/qrcode`（生成 state + 授权 URL）、`GET /api/auth/wechat/callback`（服务端 code 换 openid）、`GET /api/auth/poll`（客户端轮询取自有 JWT）、`GET /api/auth/me`。
  - 手写 HS256 JWT（`JwtTokenService`），密钥读 `Jwt:Secret`，30 天有效。
  - 历史 API：`GET /api/history`、`POST /api/history/merge`、`POST /api/history/push`、`DELETE /api/history/{seriesId}`、`DELETE /api/history`，全部 Bearer 鉴权。
  - `AccountStore`：单文件 JSON（`App_Data/account-store.json`）持久化用户与历史，按 seriesId 合并取最新 WatchedAt，上限 500 条；登录态内存字典 5 分钟过期。
  - 自带 `web.config`（AspNetCoreModuleV2，inprocess）。
- Core：新增 `IAuthService`/`IHistorySyncService` 接口、`UserProfile`/`WeChatQrCodeResult`/`LoginPollResult`/`HistorySyncResult`/`StoredSession` 模型；`IHistoryService` 增加 `ReplaceAll`；`AppSettings` 增加 `AccountApiBaseUrl`（默认 https://account.miaomiaotv.diaofanle.com）。
- Infrastructure：`ApiAuthService`（登录/会话持久化 session.json/恢复/登出）、`HistorySyncService`（云端增删改查，全用 source-gen JSON，AOT 零警告）。
- Desktop：新增微信扫码登录窗口（`LoginWindow` + `LoginWindowViewModel`），二维码用 `Net.Codecrete.QrCodeGenerator` 2.1.0 经 `QrRenderer` 渲染为 WriteableBitmap（项目已开 AllowUnsafeBlocks）；设置页新增"账号与云同步"卡片；登录后自动上传本地→回填合并结果，播放进度每 15 秒节流单条上传，删除/清空同步云端。
- 测试：新增 `ReplaceAll` 去重/最新/清空、会话持久化与登出清除的回归断言。

## 改版：登录方式从「开放平台网站应用扫码」改为「微信小程序码」（同日）

用户问微信扫码是否第三方/免费 → 核实：官方能力、非第三方，但开放平台网站应用要企业主体+300元认证，个人做不了。用户选小程序码方案。

### 关键事实（已查官方文档确认）
- 微信小程序码接口 `wxa/getwxacodeunlimit`（官方错误码 85412）：**个人主体小程序须先完成微信认证才能生成/使用小程序码**，个人认证 30 元/年（企业 300）。不是纯 0 元，故更正此前"0元可替代"说法。
- 小程序所有 request 必须 HTTPS + ICP 备案域名，且在小程序后台配 request 合法域名。
- `getwxacodeunlimit` 只能在服务端调用；scene ≤32 字符；成功返回图片二进制，失败返回 JSON（首字节 `{` 区分）。

### 改动
- 后端 `WeChatClient` 重写：access_token 缓存（提前5分钟过期 + SemaphoreSlim）、`CreateQrCodeAsync(scene)`、`ExchangeCodeAsync(code)`（jscode2session 换 openid，unionid 优先，默认昵称"微信用户+尾号"）；错误码 85412 附认证提示。
- `Program.cs`：`POST /api/auth/qrcode` 改为服务端生成小程序码返回 Base64；删除 `GET /api/auth/wechat/callback`；新增 `POST /api/auth/mini-login`（code+state → openid → JWT → CompleteLogin，校验 state 必须 pending）。
- `appsettings.json`：去掉 `WeChat:CallbackUrl`，新增 `WeChat:Page`（默认 pages/login/login）、`WeChat:EnvVersion`（release/trial/develop）。
- Core：`WeChatQrCodeResult.QrUrl` → `QrCodeBase64`。
- Desktop：`QrRenderer` 从本地画码改为 Base64→Bitmap 解码；移除 `Net.Codecrete.QrCodeGenerator` 包与 AllowUnsafeBlocks；登录窗文案改小程序流程。
- 新增 `miniprogram/` 完整小程序前端（app.json/app.js/config.js + pages/login）：扫码读 scene → 点确认 → wx.login → POST mini-login；`config.js` 的 apiBase 需用户填。
- 测试项目新增对 API 项目引用 + `FakeWeChatHandler`，验证 token 缓存、scene 传递、code 换 openid、85412 提示。
- README 账号章节重写为小程序准备（含 30 元认证、合法域名）与部署说明。
